# 两人日程设计

用户已于 2026-10-27 确认：以周视图为主，同时显示每周固定安排、单次安排和 DDL，固定安排可以只修改或取消某一次。

## 意图与范围
在现有心动手记中新增「两人日程」页面，方便 YYF 与 ZXR 看见彼此忙碌的时间和截止日期。保留网站的柔和配色、双账号登录、本机备份及云端合并同步。两个人都可维护日程，选择 YYF、ZXR 或两人共同参与。

## Approaches
采用周视图加近期 DDL 列表：能直接比较具体时间段；月视图能概览整月但时间段拥挤，单纯列表难比较空闲时间。用户已选择周视图。原生 HTML/CSS/JavaScript 实现，不新增日历依赖或外部服务。

## 行为
- 周一开始，前后切换周、回到本周；按归属人筛选。桌面七列，手机按日排列以避免横向挤压。
- 每周固定安排选择生效日期、星期、开始与结束时间，可选结束日期；单次安排选择日期与起止时间；DDL 选择日期与时间并能标记完成。
- 编辑固定安排时明确选择「整个固定安排」或「仅这一次」；单次改动以例外记录保存，取消也保存例外。删除整个安排保留删除标记，旧缓存不能复活。
- 同一天的重叠安排都可看见；跨午夜的忙碌安排首版拆为两条。所有时间按 Asia/Singapore (UTC+08:00) 解释，避免不同设备时区造成日期漂移。
- DDL 展示未完成且按截止时间排序，标注剩余时间或逾期；已完成项仍可在所属周查看和恢复。

## 数据与验证
新增 schedules 数组及 deletedItems.schedules。共享规则按稳定 ID 和 updatedAt 合并，例外 ID 按系列 ID 与原始日期确定。前后端共同检查日期、时间、归属、重复星期、文本长度、类型与例外字段。后端继续使用现有登录权限，允许两人协作维护。

## 边界
不接入外部日历、推送或邮件提醒。云端不通时继续保留本机备份并显示现有失败状态。本次完成本地代码和模拟验收，发布到生产环境沿用项目现有部署流程。
