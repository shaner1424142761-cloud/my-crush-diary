# 照片与双账号本地验收

本地实现：独立 YYF/ZXR 登录与对应打分；可信留言作者；旧备份明确恢复；私人照片上传、压缩、照片墙和大图浏览。线上未更新，未推送、部署、轮换真实凭据或写真实记录。

82 项 Node 测试通过。实际 Worker/SQLite + 两个浏览器通过：预上传预览、9张选择与10张拒绝、横竖/透明/噪声/超长合成图、合成 EXIF 旋转、坏文件、400KiB上限、认证读取、重复和并发上传、真实SQLite回滚及近容量并发、元数据失败重试、旧链接/时间、两三列布局、大图键盘和退出清理。原账号/六页面/离线恢复验收、44个公开文件扫描及两个binding的Wrangler dry-run通过。私人备份仅离线核对，343条记录及两边总分完整。

独立全分支审查后的裁定与修复：

- Important：重复暂停账号会用空数据覆盖待同步缓冲。正常与存储受限情况下的重复暂停、过期请求及退出测试先失败，再加幂等暂停保护，回归通过。
- 审查所标 Minor 的并发验收顺序被重评为需修复：正确实现不能因为任意合法到达顺序而让CI失败。按状态集合判断一个成功/一个容量拒绝，并检查实际胜出的照片存在、另一张不存在、容量精确。
- 审查所标 Minor 的选图无预览被重评为需修复：用户须先辨认照片才能写对应说明，也是已确认选图流程的要求。选择后逐张压缩生成预览，准备时禁用上传，以身份/代次保护，移出和退出撤销URL；先失败的预上传预览测试和实际浏览器验收均通过。

无延后 Minor。极端图片高度与原固定底栏遮挡问题也已实测修复；照片保留完整比例，墙面高度有上限，相册底栏改为正常文档流。
